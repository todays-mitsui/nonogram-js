← エディタに戻る

使い方

ノノグラム エディタは、ノノグラム(お絵かきロジック)の問題を作り、ブログなどの Web ページに貼って遊んでもらうための道具です。貼るのは HTML のタグ1組だけで、サーバーもアカウントも要りません。

ここにノノグラム(パズル)があります。JavaScript が動く環境で開くと遊べます。

↑ 貼るとこうなります(10x10、3色)。ここで解いてみることもできます。

1. 問題を作る

エディタを開き、マスに絵を描きます。

  • 描く: クリックやドラッグで塗ります。右クリック・Shift + クリックで消せます
  • サイズ: 幅・高さとも 5〜100 マス。縮めても枠外の絵は消えません
  • パレット: 16 色まで。2色以上にするとカラー問題になります
  • 一意解チェック: ヒントの数字だけから答えが1つに決まるかを、描くたびに調べます。「別の答えがあります」と出たら、「別の答えを見る」で違うマスを確かめて直せます
  • テストプレイ: 解く側の画面で実際に解いてみられます

保存

保存ボタンはありません。描くたびに自動で、そのブラウザの中に保存します。「作品の一覧」から開き直したり、新しく作ったりできます。

別の端末やブラウザには引き継がれません。持ち出すときは、書き出した正解図コード(タグの data-solution の値)か、そのときの URL を控えてください。エディタの「読み込み」に貼ると続きから直せます。

2. ブログに貼る

  1. エディタの「書き出し」で縦横比(縦長 3:4 / 正方形 1:1 / 横長 4:3)を選ぶ
  2. 「タグをコピー」を押す
  3. ブログの記事の HTML に貼る

コピーされるタグはこういう形です。

<div class="todays-mitsui__nonogram"
     data-solution="v2;5x5;5x5;#000;Y2BkAEI4ADEZGIBCDAA"
     data-aspect-ratio="1:1">ここにノノグラム(パズル)があります。JavaScript が動く環境で開くと遊べます。</div>
<script src="https://todays-mitsui.github.io/nonogram-js/player/v1/player.js" defer></script>
  • 貼る場所: HTML をそのまま書ける編集画面に貼ってください。はてなブログなら「HTML 編集」か Markdown モードです。見たまま編集の画面では <script> が消されることがあります
  • 1つの記事に何問でも: タグを続けて貼れます。<script> が何回出てきても問題ありません
  • 幅: 記事の本文の幅いっぱいに広がり、高さは縦横比で決まります。大きな問題で画面に収まらないときは、パズルの中でスクロールできます
  • タグの中の文: RSS リーダーなど JavaScript が動かない場所で代わりに表示されます。書き換えても構いません

3. 解く人の操作

塗る タップ / クリック。ドラッグで続けて塗れます(最初に動かした向きの1列に揃います)
× を付ける 「×」ツールを選んでタップ。マウスなら右クリックか Shift + クリックでも付きます
色を選ぶ カラー問題では、ツールバーの色のほか、ヒントの数字をタップしてもその色になります
戻す / やり直す ツールバーのボタンで1操作ずつ
罫線 マスの罫線の表示を切り替えます
リセット / 答えを見る 確認のあと、盤面を消す / 答えを表示します

解きかけの盤面は、解く人のブラウザに自動で保存されます。ページを閉じても、同じブラウザで開けば続きから解けます。

困ったとき

パズルが表示されず、タグの中の文だけが出る

<script> の行が消されているか、JavaScript が動かない場所で見ています。記事の HTML に <script src="…/player.js"> が残っているかを確かめてください。

「正解図コードが壊れています」と出る

data-solution の値が途中で切れたり書き換わったりしています。エディタからタグをコピーし直してください。

「このブラウザではノノグラムを表示できません」と出る

ブラウザが古く、必要な機能がありません。新しいブラウザで開いてください。

AI エージェントから使う

エディタは WebMCP に対応しています。対応したブラウザでは、AI エージェントがエディタの機能(盤面を描く、色を変える、一意解チェック、タグの書き出しなど)を直接呼べます。

仕様

タグや正解図コードは公開仕様です。エディタを使わずに、手で書いたりほかのツールで作ったりしても構いません。

  • 埋め込みタグ仕様(EMBED.md): タグの書き方と player.js の振る舞い
  • 正解図コード仕様(FORMAT.md): data-solution の値の形式
  • 進捗コード仕様(PROGRESS.md): 解きかけの盤面の保存形式
  • 用語集(GLOSSARY.md)
